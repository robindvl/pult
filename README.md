# Пульт Собственника

Кликабельный прототип по методологии SmirnovTech: табличный дашборд, функции конвейера (ЦКП), трекинг DIHA. Данные — моки.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Экраны

- `/` — дашборд собственника (группы: новые / текущие / финансы / личная цель)
- `/diagnostics` — самодиагностика: стадия роста, 6 блоков, роза ветров
- `/strategy` — персональная стратегия: реестр инструментов Система/Масштаб
- `/org` — функции конвейера Change / Run / Штаб + ЦКП и риски
- `/weekly` — DIHA‑трекинг + AI‑черновик (мок)
- `/metrics/[id]` — деталь метрики

## Как протестить (живой слой)

1. Переключи **Янв / Фев / Мар** в сайдбаре или над таблицей.
2. Кликни факт/название метрики → на странице метрики измени факт (например лиды `70`).
3. На дашборде появятся бейджи: разрыв / прошлое / порог / **не успеем**.
4. Нажми **В DIHA** / **Создать DIHA** → трекинг.
5. Кликай **статус** в DIHA: к запуску → в работе → сделано.
